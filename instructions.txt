HOW TO USE BONSAI 2 (local model + assistant)

1) START EVERYTHING (ONE CLICK)
   Double-click:  run.bat   (in the project folder)
   -> starts the assistant UI at http://localhost:8081
   -> also starts the Bonsai 2 model server on port 8080 automatically
      (the model loads into RAM on your first message, ~1 min on first start).

2) USE IT IN OPENCODE
   opencode --model llama.cpp/bonsai2
   (Run run.bat first so the model server is up, or start the app and
    compare answers. opencode config: ~/.config/opencode/opencode.jsonc,
    provider "llama.cpp" - restart opencode after changing it.)

3) STOP THE MODEL SERVER (optional)
   Double-click:  stop.cmd   (in the project folder)
   (The UI panel can keep running; the model just loads again on next message.)

DETAILS
   - Local API:        http://127.0.0.1:8080/v1
   - Model id:         bonsai2
   - While I reply, SEND turns into STOP (cut me off) and QUEUE holds a
     follow-up message that is answered right after the current reply.
   - That is the only launcher: run.cmd / start-server.ps1 are gone.
   - Server profile: 32k context, ~48 tok/s on an RTX 4070.
   - Live stats bar under the input shows think time / speak time,
     tokens/s, tokens used and context used/left in real time.
   - THINK: OFF/LOW/MED/HIGH selector next to SEND controls how deeply I reason
     (maps to enable_thinking / reasoning_effort on the model).
   - NEW PC CONTROLS: I can take a screenshot and really SEE your screen
     (take_screenshot), move the mouse / click / drag / type (control_input),
     read and write the clipboard (clipboard), download files into the
     workspace (download_file) and pack/unpack zip+tar archives (archive).
   - BLENDER: when Blender is open (with the "MCP for Blender" addon enabled)
     I can create/edit 3D scenes inside it, inspect the scene and screenshot
     the viewport to show you - a status light in the header shows the
     connection (CONNECTED / ADDON OFF / OFF).
   - I can ASK YOU a question with options and wait for your answer (ask_user)
     exactly like a human, and I keep a live TODO checklist on the left panel
     (todo_write).
   - The model stays loaded (resident) the whole time the app runs - there is
     no idle timeout that unloads it, so replies never stall after a pause.
     To free the memory yourself click the EJECT button in the header (it
     loads back automatically on the next message).
   - Chat history is saved in the browser AND in
     %APPDATA%\BonsaiAsistent\chats.json, so conversations survive restarts.
